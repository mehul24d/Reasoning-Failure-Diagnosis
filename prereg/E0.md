## Research question
E0 is a prerequisite check, not a research question. It decides which SAE layers can be used for
the SAE-feature readout in E2. It also checks whether HRCD-style "sparsity collapse" (an active
fraction L0/D < 0.05) can tell failed tokens from correct ones once tokens are matched. The plan
reports it for completeness (Appendix A).

## Hypothesis
1. Gemma Scope residual SAEs reconstruct instruction-tuned reasoning traces well enough at most
   layers.
2. After matching, the difference in L0 and in feature entropy H between failed and correct
   tokens is small (no "sparsity collapse" signal).

## Falsification / decision criteria
* **A layer passes SAE validation** if FVU ≤ 0.40 **and** ΔCE ≤ 0.20 nats/token. Both are reported
  for every layer. Failing layers are excluded from every SAE analysis.
* **E0 has no pass/fail.** ΔL0, ΔH and Cohen's d are reported per depth band with 95% CIs and
  Holm-adjusted p-values. A Holm-adjusted p < 0.05 in any band is reported as a matched sparsity
  difference. Because content and evaluation directions are residual-based, a difference does not
  block later steps.

## Data
* **Population:** GSM8K **train**, with 500 problems sampled using seed 0. No GSM-Symbolic template
  (the study population) is used before its split is pre-registered.
* **Traces:** greedy (T = 0, no repetition penalty, batch size 1), prompt styles `marked_p0` and
  `terse_p0`, giving 1,000 traces. `max_new_tokens` = 512.
* **Correctness:** computed by `parsing/answers.py`: the last number after the last answer marker,
  on that marker's line. A trace with no marker counts as incorrect.
* **SAE validation set T:** the generated-trace tokens of the first 200 traces. Prompt tokens are
  not scored.

## Procedure
* **Hook site:** `blocks.{l}.hook_resid_post`, TransformerLens without weight processing.
* **FVU (eq. 2):** pooled over all tokens in T, using the global mean over T.
* **ΔCE (eq. 3):** the SAE reconstruction replaces the residual at every non-BOS position.
  ΔCE = mean over trace tokens of (−log p_spliced + log p_clean).
* **E0 layers:** up to 3 passing layers per depth band, spaced evenly. Depth bands are thirds of
  the layer range (2B: 0–8 / 9–17 / 18–25; 9B: 0–13 / 14–27 / 28–41).
* **E0 token measures (eq. 9):** L0 = number of features with a_j > 0. H = Shannon entropy of the
  normalised active magnitudes.
* **Matching:** exact on (layer, token id, relative-position bin [5], residual-norm quintile
  within layer, reconstruction-error quintile within layer). The reconstruction-error key is how
  the plan's "controlled for per-token reconstruction error" is put into practice. Only strata
  that contain both failed and correct tokens are used.
* **Effect:** ΔX is the average over strata of (mean_fail − mean_correct), weighted by the number
  of failed tokens in each stratum. Cohen's d (eq. 10) is ΔX divided by the pooled SD of the
  matched samples, with correct tokens re-weighted to the failed stratum distribution.
* **Uncertainty:** template-clustered bootstrap with 10,000 resamples, 95% percentile CI, and a
  two-sided bootstrap p-value. For GSM8K each problem is its own cluster. Holm correction is
  applied across the 3 bands, separately for ΔL0, ΔH, d(L0) and d(H).
